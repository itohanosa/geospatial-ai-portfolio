# TrustEO Project Summary

## Problem

Earth observation foundation models are becoming powerful tools for satellite image analysis, but their reliability in real-world climate and disaster-risk applications is still uncertain.

A model may perform well in one region but fail in another. For applications such as flood mapping, land-cover change, and burn scar detection, this creates a serious problem because decision-makers need maps they can trust.

## Objective

TrustEO aims to evaluate how reliable Earth observation foundation models are when applied to new regions and environmental hazards.

## Main Contribution

The project will move beyond accuracy-only benchmarking by evaluating:

- Geographic transfer
- Uncertainty calibration
- Explanation reliability
- Robustness across sensors and regions
- Practical decision-support value

## Expected Output

The project will produce:

1. A reproducible GitHub benchmark
2. A research manuscript
3. Example notebooks
4. Evaluation figures
5. A postdoctoral research proposal concept
