# Maui Wildfires 2023: Satellite-Based Burn Severity and Impact Assessment

## Overview

This project uses Sentinel-2 imagery, machine learning, and cloud-based geospatial analytics to assess the impacts of the 2023 Maui wildfires.

The workflow identifies burned areas, estimates affected population, evaluates land-cover impacts, and analyzes vegetation recovery using time-series remote sensing data.

## Objectives

- Detect wildfire burn scars
- Quantify burned area extent
- Assess affected population
- Evaluate land-cover impacts
- Monitor vegetation recovery

## Study Area

Maui County, Hawaii, USA.

## Datasets

- Sentinel-2
- ESA WorldCover
- WorldPop
- Google Earth Engine

## Methods

- Normalized Burn Ratio
- Normalized Difference Vegetation Index
- Random Forest classification
- Population exposure analysis
- Land-cover impact assessment
- Vegetation recovery time-series analysis

## Key Results

- Detected burned area: **7,174 hectares**
- Estimated affected population: **approximately 160,000 people**
- Grassland represented the largest affected land-cover class.
- Vegetation index time series showed decline during the wildfire event and recovery afterward.
